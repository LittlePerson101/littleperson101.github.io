Pokeloader Maven

You can access my maven repository to use Pokeloader in your own mod environments.

Repository

maven {

Dependencies (Example)

// Fabric
modImplementation "io.github.littleperson101.pokeloader:pokeloader-fabric:1.0.0"

// Forge
implementation fg.deobf("io.github.littleperson101.pokeloader:pokeloader-forge:1.0.0")

// NeoForge
implementation "io.github.littleperson101.pokeloader:pokeloader-neo:1.0.0"
